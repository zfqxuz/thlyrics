## 1. 现状：先把事实对齐（已逐行核对代码）

| 概念 | 现在是什么 | 代码位置 |
|---|---|---|
| ✓ 已掌握 | 词级时间戳，正=标了，负=取消 | `S.known` |
| ♥ 收藏 | **曲目级**，不是词 | `S.fav` |
| 学词列表 | `deckList()`：曲库词 → 范围/词性筛选 → `hideKnown` 时剔掉已掌握 | `deckList()` |
| **复习** | 牌组 = `VOCAB.filter(v => !isKnown(v) && LIBW.has(v.word))` 均匀抽 20 个；「记住了」会**顺手把词标成已掌握**；纯自评，没有任何验证 | `startReview() / renderReview()` |
| 生词本 | 展示的其实是**已掌握**那批词 | `renderMine()` |
| 详情页上下词 | 每次从 `deckList()` **现算** → 标完之后 `at = -1`，两个按钮直接消失 | `showWord()` |
| 返回 | `goBack()` = `history.back()`，而翻页会压历史 → 退回到**上一个词** | `goBack()` / `leaveDetail()` |
| 隐藏已掌握 | `<button class="tlink">● 隐藏已掌握</button>`，整行朱红 + 前导大圆点 | `renderLearn()` |

**三个结论**
1. 现在的复习**跟星标毫无关系**，而且是**纯自评**（用户说"记住了"就算记住）——这正是要换掉的东西。
2. 复习还会**反向污染**已掌握（「记住了」= 自动标已掌握），跟"复习不该是已掌握"直接冲突。
3. 之前那版「返回恢复浏览位置」已被回退（当时它带崩了路由），**现在代码里没有滚动记忆**，这次要连它一起做回来。

## 2. 三个必改项

### 2.1 「标为已掌握」之后，上一词 / 下一词不能消失

**根因**：`showWord()` 里的 `prev/next` 是从 `deckList()` **现算**的。一点「标为已掌握」→ `toggleKnown()` → 整页重渲染 → 该词被隐藏筛选剔除 → `at = -1` → `prev/next = null` → 按钮没了（还顺带滚了一下屏）。

**方案：详情页的翻页上下文，进入时定格，之后不随筛选/标记变化。**

```
进入 #/word/<id> 时记下：
  wordNav = { ids:[…来源列表当时的 id 顺序], i:当前下标, from:'#/learn' }
```

1. `prev/next` **只从 `wordNav.ids` 取**，不再调 `deckList()`；
2. 标为已掌握 → **原地改按钮**（类名 + 文案），**不重渲染整页**、不滚动；
3. 列表两端不再"消失"，改成**置灰不可点**（保留占位，按钮行不跳动）；
4. 深链接直接开 `#/word/123`（没有上下文）→ 进入时用当时的 `deckList()` 现建一次快照，之后冻结。

### 2.2 「返回」应该回到上一**页**，不是上一个**词**

**根因**：`goBack()` 无条件 `history.back()`；而翻页走 `location.hash = …` → 每翻一个词压一条历史。

| 动作 | 历史操作 |
|---|---|
| 从列表点进词 | **push** 一次 `#/word/<id>`，记下 `wordNav.from`（唯一的详情页历史） |
| 详情页内 ‹ / › 翻词 | **`history.replaceState`** + 手动重渲染（不进历史） |
| 点「返回」 | **`go(wordNav.from)`**，不做 `history.back()` |
| 原生返回键 / 左缘右划 | 同一个 `leaveDetail()`，三处入口行为统一 |

**配套**：把滚动记忆做回来（离开列表记 `{hash, scrollY}`，从详情返回时恢复；换筛选/排序/tab 就丢弃记忆）。
⚠️ 上次它带崩路由的原因：删了 DOM 节点却还留着 `$('p-edit').onclick` → **空引用 → boot 抛异常 → 路由全挂**。这次规矩：**任何 `$('id')` 先判存在**，且改完必须点一遍四个 tab。

`#/track/<id>` 有同样毛病，一起改。

### 2.3 「● 隐藏已掌握」→ 变成「标签」

直接按你的口径：**默认就不含已掌握，已掌握是一个标签**。详见 §6。

## 3. 产品调研：多邻国 / 有道（想法 · 呈现形式）

> 说明：本轮**实地抓取基本失败**——多邻国 help / blog、有道 help 都是 JS 单页，搜索引擎在这个环境返回的是乱结果，Wikipedia 也连不上。所以下面是我对这几款产品的既有认知整理，我把它当作**设计依据**而不是"考据结论"；如果你要更硬的出处，我可以换个方式再取一次。

### 3.1 多邻国：它真正的护城河是「不许你自评」

| # | 机制 | 值得学的**想法** |
|---|---|---|
| 1 | **练习即验证** | 系统出题判定你答没答对，**不给"我觉得我会了"这个选项** |
| 2 | **一轮 = 一小组题**（10~15） | 短、有终点、有进度条 |
| 3 | **答完立刻给正解** | 答错不只打叉，**把正确答案同时标出来** |
| 4 | **阻断式反馈** | 反馈条滑出时必须按「继续」才走，不让你划过去 |
| 5 | **错题本轮回炉** | 答错的题重排到本轮末尾，必须再做对一次 |
| 6 | **同一知识点换角度反复问** | 听、选、拼、填轮着来，防"记住选项位置" |
| 7 | 熟练度会衰减 → 提供"练弱项" | 对应到我们就是「到期复习」 |

**呈现形式（学的是"形"）**：一屏只有一道题、题面居中大字；选项是**整行卡片**不是小按钮；反馈用**颜色 + 图标 + 底部条**三层同时给；进度条很细（2~4px），不用数字压人；结算页一个大数字 + 分项。

**不照搬**：生命值、连胜、经验、排行榜、宝石、庆祝动画、每日目标。这些是留存层，我们要的是学习层。

### 3.2 有道词典 / 百词斩：它真正的护城河是「排期」

| # | 机制 | 值得学的**想法** |
|---|---|---|
| 1 | **生词本 + 标签** | "标记"是用户主动的收藏动作，和"熟练度"是两回事 |
| 2 | **记忆曲线排期** | 新词按 几小时→1天→2天→4天→7天→15天 排；**UI 上只露一句"今日需复习 N 个"** |
| 3 | **卡片翻转** | 正面词、点一下看释义（"先回忆、再核对"） |
| 4 | **多题型验证** | 看词选义 / 听音选词 / 拼写填空 |
| 5 | **熟悉度进度** | 每词一个掌握度，答对涨、答错落 |
| 6 | 统计：连续天数、累计词数 | 留存层，**不取** |

### 3.3 我们取这 4 条 + 一个别人给不了的东西

| 取什么 | 来自 | 落到我们这 |
|---|---|---|
| **A. 验证而非自评** | 多邻国 | 复习改成**答题**，取消「记住了/还不熟」自评 |
| **B. 答完立刻给正解 + 错题本轮回炉** | 多邻国 | 答错同时高亮正确项；该题重排到本轮末尾 |
| **C. 到期才复习（间隔递增）** | 有道 / 艾宾浩斯 | 每词算一个"下次到期"，**只活在巩固条的一行数字里**，不做曲线面板 |
| **D. 一屏一题 + 整行卡片 + 底部反馈条** | 多邻国（形） | 复习页版式重做 |
| **E. 标签化收藏** | 有道 | 星标 + 已掌握 + 错词，都是**用户的标签**，不是系统的判定 |

**★ 别人给不了的：歌词挖空。**
多邻国、有道都不可能有的题型 —— 我们库里每个词都挂着**真实歌词例句 + 时间轴 + 音频**。所以可以出：
「**听这一句歌词，把缺的那个词选出来**」。
这是这套产品的独有资产，用它出题，既是复习也是"回到歌里"，别人抄不走。

- 星标插在图标组**最左**，让 ✕ 永远在最右（拇指肌肉记忆不破）；

### 4.2 三种"标记"的分工

| 标记 | 用户心里的话 | 后果 | 存储 |
|---|---|---|---|
| **★ 星标** | "我要留着、想再见到" | 进复习（主来源） | `S.star` |

| ♥ 收藏 | "这首歌我喜欢" | 曲目级，不动 | `S.fav` |

一句话：**已掌握＝做减法（别给我看了）；星标＝做加法（下次还要给我）。**

## 5. 复习：从「自评」改成「验证」（你的要求③）

### 5.1 一轮是什么

**一轮 12 题**，来源仍是 **星标 ∪ 错词**（守住你的口径），"什么时候出现"由到期决定（§5.4）。

```
错词（答错过）按 e 降序  →  星标按加入时间倒序  →  两串交替取（1 错 1 星）
  →  只保留"已到期"的  →  开局 12 题，答错的追加到本轮末尾
```

### 5.2 题目版式（学的多邻国的"形"）

```
┌──────────────────────────────────────────────┐
│ ‹ 结束          ●●●●○○○○○○○○                 │  ← 2px 细进度条
│                                              │
│                这个词是什么意思？              │  ← 题干小字 ink-3
│                                              │
│                    そら                       │  ← 题面：衬线大字 38px
│                                              │
│  ┌────────────────────────────────────────┐  │
│  │  天空                                   │  │  ← 整行卡片，高 52px
│  ├────────────────────────────────────────┤  │
│  │  大海                                   │  │
│  ├────────────────────────────────────────┤  │
│  │  星                                       │  │
│  ├────────────────────────────────────────┤  │
│  │  月                                       │  │
│  └────────────────────────────────────────┘  │
└──────────────────────────────────────────────┘
        ↓ 点完之后，底部滑出反馈条（阻断式）
┌──────────────────────────────────────────────┐
│  ✗ 正确答案：天空                [ 继续 ]      │
└──────────────────────────────────────────────┘
```

### 5.3 四种题型（按词的可出题条件自动挑）

| # | 题型 | 题面 | 选项 | 适用条件 |
|---|---|---|---|---|
| 1 | **看词选义** | 大字＝词 | 4 个中文释义 | 任何词 |
| 2 | **看义选词** | 大字＝释义 | 4 个词 | 任何词 |
| 3 | **听音选词** | 一个 🔊（自动发音） | 4 个词 | 有发音的词 |
| 4 | **歌词挖空** ★独有 | 一句真歌词，目标词处留 `▁▁`，旁边一个 ▶ 可听这句 | 4 个词 | 有例句的词 |

- 干扰项：**同词性 + 相近难度**（JLPT/标日同级）从曲库抽 3 个；不够就放宽到全库；
- 同一词在一轮里尽量换题型（防"记住选项位置"）。

### 5.4 判定 · 反馈 · 回炉（核心的三条）

1. **点选项即判**，选项锁定不可改；
2. **对**：所选变绿 + ✓，其余淡出；**错**：所选变红 + ✗，**同时把正确项高亮成绿**（这条最重要——不是只告诉你错了，是直接给你看正解）；
3. **底部滑出反馈条**，必须按「继续」才走（阻断式，不让你划过去）；
4. **错题回炉**：答错的题 `e += 1`，并**追加到本轮队列末尾**，本轮内必须再做对一次；
5. **熟练度**：答对 `s = min(5, s+1)`；答错 `s = max(0, s-2)`（比多邻国温和，不一次清零）。

### 5.5 到期复习（有道的核心，但**藏起来**）

```
到期间隔（按熟练度 s 取）：0.5 小时 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天
s = 0 且 e > 0  →  永远视为到期（每天都会出现，直到答对）
刚星的词       →  没有记录，立即到期（当天就能复习到）
```

- UI 上**只露一行**：学词页巩固条的「今天 12 个」，**不做曲线、不做日历、不做"下次复习时间"**；
- 曲线只活在那一行数字里 —— 这就是"轻量化"的边界。

### 5.6 结算页

```
              一轮结束
        12 题 · 答对 10 · 回炉 2
       [ 再来一轮 ]    [ 回我的词 ]
```
（多邻国的结算页也是"一个大数字 + 分项"，但**不要**它的经验/宝石/连锁。）

### 5.7 明确不做（防变重）

❌ 生命值 ❌ 连胜 ❌ 经验 ❌ 排行榜 ❌ 庆祝动画 ❌ 每日目标 ❌ 打卡日历 ❌ 遗忘曲线面板 ❌ 拼写题、句子排序题（对"看懂歌词"这个目标是过度设计）

### 6.1 巩固条（学词里的"复习巩固"，轻量）

- 位置：进度条下面、筛选区上面，一行；
- 内容：`复习巩固　今天 12 个　　　开始 ›`（数字用 `--ink`，其它 `--ink-2`，上下各一条 hairline）；
- 点「开始」→ 直接进复习，**牌组＝当前到期的那批**，不重新洗；
- 一个都没有时：整行换成一句灰字 —— `遇到想留住的词点 ★；答错的词会自动排进来`（空着也是在教功能）。

### 6.2 「我的词」页（原「生词本」）

原「生词本」展示的是**已掌握**那批词，新模型下它已经不是复习的来源，会误导。最小改法：


## 8. 数据与云端同步

```js
S.star = { [wordId]: 时间戳 }          // 正 = 星标，负 = 取消（与 S.known 完全同构）
S.rev  = { [wordId]: {                 // 一个词一条作答档案
             s: 熟练度 0..5,
             e: 累计答错次数,            // 错词池 + "常见的错误词汇"
             d: 下次到期时间戳,
             t: 最后作答时间             // 合并用
          } }
```

**合并规则**（必须一起改，否则多端互相顶掉）：
- `star` 抄 `known` / `fav` 的现成规则：`|时间戳|` 大的赢，负值 = 取消，早于 `clearedAt` 的丢弃；
- `rev` 按 `t` 取新的一条（和 `S.words` 的合并方式同构）；
- `mergeStates()` 的默认字典、`loadLS()` 的兜底、「清空进度」三处都要补上这两个 key。

**老数据无需迁移**：旧用户没有 `rev` → 所有词 `s=0, e=0` → 不进池；`known` 也不再影响复习。
